Corrective Action Tracker

Follow every action from raised to closed. An action is only closed when someone other than its owner has checked, in practice, that it was done and that it works. Actions can link to a risk in the Risk Register, so a flagged risk becomes tracked work.

Actions tagged Example hold made up details so you can see how the rules work. Do not use them for real decisions. Edit or delete the examples and add your own.

This tracker shows whether actions are being completed and checked. A closed action does not prove the risk is controlled. After closing an action, update the control status and re-score in the Risk Register. A competent person must judge the result.

    If the check finds the action does not work, the tool reopens it automatically and keeps the record of the failed check in the change log.

    Rules the tool applies

    • Moving a due date needs a written reason. The move is recorded, and an action moved twice or more is flagged.
    • The change log records creation, status changes and due date moves. It cannot be edited in the tool. It lives in this browser, so it is a working record and not tamper proof. For a record that cannot be altered, use the multi-user Safety Risk Platform.
    • An action is overdue when it is open or in progress after its due date.
    • An action that is done but unchecked for more than the check window below is flagged.
    • If the linked risk has severity 4 or 5 and the action relies on procedures or PPE, the tool asks you to look higher in the hierarchy of controls (eliminate, substitute, engineering).
    • If the due date is later than the default timescale for the linked risk's rating, the tool flags it.
    • Linked risks are read from the Risk Register stored in this browser. This tool never changes the register.
    • The rating shown for a linked risk counts residual scores only when a control is verified working within the last 12 months, the same rule as the register.

    Default timescales

    These are this tool's own defaults, not a legal or published standard. Set them to match your organisation's policy. They only create flags and do not stop you saving.

    Limits

    Decision support only. It does not replace a suitable and sufficient risk assessment, or the judgement of a competent person. Data stays in this browser unless you save a data file. It has no sign-in, so it cannot prove who did what.
