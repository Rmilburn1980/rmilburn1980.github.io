5 Whys root cause tool

Define the problem, ask why with evidence at each step, test the logic in reverse, then set actions and verify the fix held. Loads a worked example from a real stoppage on Line 8 and prints as a one page report.

Cycle time and waste analysis tool

Time observation study with VA/NVA split, takt time comparison and a TIMWOODS waste breakdown, shown as both a bar chart and a radar profile. Works for any process, timed live in the browser.

Standard Minute Value tool

Work measurement tool for industrial engineering: run a time study, calculate SMV, line efficiency and production targets, with a formula reference, practice problems and MOST sequence models.

7S audit dashboard

Interactive workplace organisation audit covering Sort, Set, Shine, Standardize, Sustain, Safety and Spirit, with data kept on the device by default and optional shared collection through a Google Sheet.

SIPOC and value stream map tool

Scope a process with a SIPOC, then map the current state: cycle times, queues, takt, lead time, process cycle efficiency and rolled throughput yield. Works for any business process, in manufacturing or services, and prints as a report.

EHS and Production Supervisor roles

Safety evidence and management system readiness, built from scratch.

EHS Readiness Dashboard

Five tabs: overview, safety evidence, an ISO 14001:2026 self-assessment, the H&S management system on the POPMAR model, and a qualifications roadmap.

Risk Assessment Dashboard

A 5 x 5 risk register where residual scores only count once a control is verified working. Flags missing evidence, stale checks and High risks that lack a second reviewer.

Swiss Cheese Layers of Defence

Layers of defence tested with real check counts. Shows cautious figures, how weak the evidence is, and how much the layers may fail together. Links to the risk register.

Corrective Action Tracker

Actions from audits, incidents and risk reviews, tracked to closure. An action only closes once someone other than its owner has checked that it works. Flags overdue actions and moved due dates, and links to the risk register.

Bow-tie Builder

A hazard drawn as a bow-tie: threats on the left, consequences on the right, barriers between. A barrier only counts once it is verified working, and every path with none is shown as a gap.
