Operations Manager roles

Running a line to a set of measures, and developing the people who run it.

Dashboard

SQCDP Interview Evidence Dashboard

Interview evidence organised on the SQCDP framework: Safety, Quality, Cost, Delivery and People.

Open dashboard Dashboard

Skills matrix and cross-training

Skills by operator as radars or a matrix, the 3x3 cross-training programme, and how I developed people.

Coverage from 36% to 86.6% in two years. Three roles from about 70% to 100% in five months.
Team totals are verified. Person-level detail is illustrative and names are anonymised. Open dashboard Tool

Skills Matrix Builder

Build a matrix for any team. A level only counts once someone other than the operator has signed it off, sign-offs expire, and single points of failure and the next people to cross-train are shown. Opens with a made-up example.

Open tool Dashboard

Company Skills Dashboard

Every team's skills matrix rolled up into one management view. Shows cover against target, critical skills with too few signed-off people, sign-offs about to expire, and where the matrix claims more than the checks support. Opens with made-up teams.

Open dashboard Tool

OEE and Downtime Log

Record shifts and stops, work out availability, performance, quality and OEE from the counts, and rank the reasons time was lost in a Pareto. Leaves out runs with impossible or unchecked figures and lists them. Opens with made-up examples.

02

Continuous Improvement roles

Finding the root cause with data, measuring the work, and making the gain stick.

Flagship project

DMAIC project board

Lean Six Sigma Green Belt project on First Pass Yield at Stage 8 of the caravan line, from Define to Control.

Low 50s baseline to a sustained 96%+, with individual weeks at 100%.
FPY figures are verified production results. The C&E matrix and PFMEA scoring are the Green Belt project workup. Open project board Tool

5 Whys root cause tool

Ask why with evidence at each step, test the logic in reverse, then set actions and verify the fix held. Loads a worked example from a real stoppage on Line 8 and prints as a one page report.

Open tool Tool

Cycle time and waste analysis tool

Time observation study with VA/NVA split, takt time comparison and a TIMWOODS waste breakdown, as a bar chart and a radar profile. Works for any process, timed live in the browser.

Open tool Tool

Standard Minute Value tool

Run a time study, calculate SMV, line efficiency and production targets, with a formula reference, practice problems and MOST sequence models.

Open tool Dashboard

7S audit dashboard

Workplace organisation audit covering Sort, Set, Shine, Standardize, Sustain, Safety and Spirit. Data stays on the device by default, with optional shared collection through a Google Sheet.

Open dashboard Tool

SIPOC and value stream map tool

Scope a process with a SIPOC, then map the current state: cycle times, queues, takt, lead time, process cycle efficiency and rolled throughput yield. Prints as a report.

Open tool Tool

SPC Control Chart Tool

Individuals and moving range, or X-bar and range, charts with limits set from a baseline you choose. Marks each signal with the rule that fired, and shows Cp and Cpk only when the baseline is stable and long enough. Opens with made-up data.

Open tool
03

EHS and Production Supervisor roles

Safety evidence and management system readiness, built from scratch.

Start here

EHS Readiness Dashboard

Five tabs: overview, safety evidence, an ISO 14001:2026 self-assessment, the H&S management system on the POPMAR model, and a qualifications roadmap.

Open dashboard Dashboard

Risk Assessment Dashboard

A 5 x 5 risk register where residual scores only count once a control is verified working. Flags missing evidence, stale checks and High risks that lack a second reviewer.

Open dashboard Dashboard

Swiss Cheese Layers of Defence

Layers of defence tested with real check counts. Shows cautious figures, how weak the evidence is, and how much the layers may fail together. Links to the risk register.

Open dashboard Tracker

Corrective Action Tracker

Actions from audits, incidents and risk reviews, tracked to closure. An action only closes once someone other than its owner has checked that it works. Flags overdue actions and moved due dates.

Open tracker Tool

Bow-tie Builder

A hazard drawn as a bow-tie: threats on the left, consequences on the right, barriers between. A barrier only counts once it is verified working, and every path with none is shown as a gap.

Open tool Tool

Quick Exposure Check

Ergonomics exposure for back, shoulder and arm, wrist and hand, and neck, scored from observer and worker answers. Prints a one-record assessment and keeps a saved history. Opens with example data.

Open tool Tool

Causal Tree Builder

An incident traced back through immediate, underlying and root causes as a tree of facts. Flags assumed evidence, branches that stop before a system cause, and actions nobody independently checked. Opens with a made-up example.

Open tool Tool

Incident and Near-Miss Log

Logs incidents and near misses, checks each against the RIDDOR 2013 reporting rules, and shows overdue reports, uninvestigated serious events and actions closed without an independent check. Hands off to the Causal Tree Builder and Corrective Action Tracker. Opens with made-up examples.

Open tool
