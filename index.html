5 Whys root cause analysis

Ask why with evidence at each step, test the logic in reverse, then set actions and verify the fix held. Loads a worked example from a real stoppage on Line 8 and prints as a one page report.

Open tool Tool

Cycle time and waste analysis

Time observation study with VA/NVA split, takt time comparison and a TIMWOODS waste breakdown, as a bar chart and a radar profile. Works for any process, timed live in the browser.

Open tool Tool

Standard minute value tool

Run a time study, calculate SMV, line efficiency and production targets, with a formula reference, practice problems and MOST sequence models.

Open tool Dashboard

7S audit review

Workplace organisation audit covering Sort, Set, Shine, Standardize, Sustain, Safety and Spirit. Data stays on the device by default, with optional shared collection through a Google Sheet.

Open dashboard Tool

SIPOC and value stream mapping

Scope a process with a SIPOC, then map the current state: cycle times, queues, takt, lead time, process cycle efficiency and rolled throughput yield. Prints as a report.

Open tool Tool

SPC control chart tool

Individuals and moving range, or X-bar and range, charts with limits set from a baseline you choose. Marks each signal with the rule that fired, and shows Cp and Cpk only when the baseline is valid.

Open tool Tool

Gemba walk tracker

Log what you see on a walk and trace each observation to its owner, the evidence that closed it and the re-walk that proved the fix held. Links every finding to an SQCDP measure and a date.

Open tool Tool

A3 problem solving sheet

One page from background to follow-up. Flags an unconfirmed root cause, blame wording, countermeasures with no independent check, and a close-out where the result was not measured or the change was not standardised. Prints on A3. Opens with made-up example data.

EHS and operational safety leadership

Safety evidence and management system readiness, built from scratch.

Start here

EHS Readiness Dashboard

Five tabs: overview, safety evidence, an ISO 14001:2026 self-assessment, the H&S management system on the POPMAR model, and a qualifications roadmap.

Open dashboard Dashboard

Risk assessment register

A 5 x 5 risk register where residual scores only count once a control is verified working. Flags missing evidence, stale checks and High risks that lack a second reviewer.

Open dashboard Dashboard

Swiss Cheese layers of defence

Layers of defence tested with real check counts. Shows cautious figures, how weak the evidence is, and how much the layers may fail together. Links to the risk register.

Open dashboard Tracker

Corrective action tracker

Actions from audits, incidents and risk reviews, tracked to closure. An action only closes once someone other than its owner has checked that it works. Flags overdue actions and move-on dates.

Open tracker Tool

Bow-tie Builder

A hazard drawn as a bow-tie: threats on the left, consequences on the right, barriers between. A barrier only counts once it is verified working, and every path with none is shown as a risk.

Open tool Tool

Quick Exposure Check

Ergonomics exposure for back, shoulder and arm, wrist and hand, and neck, scored from observer and worker answers. Prints a one-record assessment and keeps a saved history.

Open tool Tool

Causal tree builder

An incident traced back through immediate, underlying and root causes as a tree of facts. Flags assumed evidence, branches that stop before a system cause, and actions nobody independently checks.

Open tool Tool

Incident and near-miss tracker

Logs incidents and near misses, checks each against the RIDDOR 2013 reporting rules, and shows overdue reports, uninvestigated serious events and actions closed without an independent check.
