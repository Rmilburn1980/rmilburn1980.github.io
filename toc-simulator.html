How the figures are worked out

Effective seconds per unit = cycle time ÷ uptime ÷ number in parallel. Capacity per shift = working seconds ÷ effective seconds. Takt time = working seconds ÷ demand. The bottleneck is the station with the longest effective time (the first one if tied).

Released work = bottleneck capacity × release percentage. A buffer covers a stoppage for buffer units × bottleneck effective time. Any stoppage longer than that cover is lost bottleneck time. The model treats the stoppage as happening immediately upstream of the bottleneck, early in the shift before any extra released work has queued in front of it. Below 100% release, the bottleneck is already short of work, so a stoppage only costs output once it eats into what was released.

Work in progress = starting buffer + work released but not completed. Flow time uses Little's Law: work in progress at shift end ÷ output rate, so it estimates how long work released at the end of the shift will take to come out. It is not an average across the shift. This is a simplified steady flow model with a full buffer at the start. It does not model random variation, travel time or work inside each station.
